# GATE G6 — the M3 simple material corpus (M3_SIMPLE_MATERIAL_DESIGN.md §7).
#
# Paths are relative to the -Sc2Mat arm's corpus root
# (C:/Projects/WhiteoutLib/Corpus). Bare path per line, no scenario tokens.
#
# Run:
#   .\scripts\render-diff.ps1 -Record -Sc2Mat -Golden
#   ... material change ...
#   .\scripts\render-diff.ps1 -Check  -Sc2Mat -Golden
# and the deferred-light sub-arm:
#   .\scripts\render-diff.ps1 -Record -Sc2Mat -Golden -DebugLight
#
# Baselines are PROGRESSIVE (each material phase legitimately changes what M3
# draws). NOTE: since the simple material system became the default M3 render
# path, the -M3 arm renders through the SAME lit pipeline — its golden is no
# longer an unlit vacuity anchor, and a shared model's m3/sc2mat goldens are
# legitimately byte-identical. Vacuity is checked by eye instead: a green
# record whose image is a flat silhouette proved nothing.
#
# Textures: the corpus ships bare `.m3` files, so layer textures resolve
# through the provider's SC2 CASC install (the mod-prefix fallback in
# CascSource). Record and check on a machine with StarCraft II installed —
# without it every layer falls back to white and the baselines mean nothing.
#

# comparable) plus models chosen for the layer axes they exercise.
